🎯

分子-蛋白质对接

评估模型预测小分子与靶蛋白结合亲和力的能力。包含PDBbind、CSAR、DUD-E等标准数据集，支持盲对接和柔性对接评估。

💊

ADMET预测

药物吸收、分布、代谢、排泄和毒性预测。覆盖Caco-2渗透性、CYP450抑制、hERG毒性、血浆蛋白结合率等13个ADMET端点。

🔬

先导化合物优化

评估模型在保持活性的同时优化药物性质的能力。包括溶解度改善、代谢稳定性提升、选择性增强等优化任务。

⚡

多目标药物设计

同时优化多个药物性质的帕累托前沿评估。支持活性-选择性-ADMET多目标联合优化基准测试。

快速开始

三行代码运行基准测试

# 安装 DrugCLIP Benchmark
pip install drugclip-benchmark

# 运行完整基准测试
from drugclip_benchmark import BenchmarkSuite

suite = BenchmarkSuite(model="drugclip-large", tasks="all")
results = suite.run(device="cuda")
results.plot_leaderboard()
# 单任务评估
from drugclip_benchmark import DockingBenchmark

bench = DockingBenchmark(dataset="pdbbind_2020")
score = bench.evaluate(model, split="test")
print(f"Spearman ρ: {score.spearman:.3f}")
