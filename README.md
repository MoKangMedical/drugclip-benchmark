# DrugCLIP Benchmark

Drug virtual screening benchmark platform based on CLIP architecture.

## Features
- 12 benchmark datasets
- 8 evaluation models
- 4 core tasks: Docking, ADMET, Lead Opt, Multi-objective

## Quick Start
```bash
pip install drugclip-benchmark
python -m drugclip_benchmark.run --model drugclip-large --tasks all
```
